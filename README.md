## Description

This project was developed as part of the Machine Learning course assignment. It focuses on the classification of American Sign Language (ASL) gestures using the **Sign Language MNIST** dataset (28x28 grayscale images across 24 classes representing letters A–Y, excluding J and Z).

**Key Features:**
* **Data Preprocessing & Normalization:** Pixel values normalized to [0, 1] with an 80/20 stratified train/validation split.
* **Exploratory Data Analysis (EDA):** Class distribution and visual sample inspection.
* **Classification Models:** Development and evaluation of machine learning classifiers.
* **Hidden Phrase Challenge:** Application of the final trained model to decode sequences of images into readable text phrases.
